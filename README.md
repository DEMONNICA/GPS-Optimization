> [!IMPORTANT]
> Features ✨:
> 1. Optimizes GPS configuration for faster cold, warm, and hot start.
> 2. Enables multi-satellite support — `GPS`, `GLONASS`, `BeiDou`, `Galileo`, `QZSS`, and `SBAS`.
> 3. Configures assisted GPS servers for faster location fix.
> 4. Activates high accuracy location mode and all location providers on every boot.
> 5. Grants location permissions to Google services for optimal positioning.
> 6. Refreshes satellite ephemeris data on every boot for improved accuracy.
> 7. Forces location service to reload configuration on every boot.
> 8. Backs up original GPS configuration and restores automatically on uninstall.

> [!TIP]
> 1. Supports `APatch` `KernelSU` `Magisk` and their forks.
> 2. Minimum Android `10 SDK 29`.
> 3. For best results, use [Meta — Hybrid Mount](https://github.com/Hybrid-Mount/meta-hybrid_mount/releases) for system file overlay support.
